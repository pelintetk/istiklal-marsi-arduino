# İstiklal Marşı - Arduino

Arduino Uno ile buzzer ve I2C LCD kullanarak
İstiklal Marşı çalan devre projesi.

## Malzemeler
- Arduino Uno
- Pasif Buzzer
- I2C LCD 16x2
- Jumper kablo

## Bağlantılar
| Bileşen | Arduino Pin |
|---------|------------|
| Buzzer + | Pin 7 |
| Buzzer - | GND |
| LCD SDA | A4 |
| LCD SCL | A5 |
| LCD VCC | 5V |
| LCD GND | GND |
